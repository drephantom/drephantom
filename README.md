## 我关注的实践

- **有来源的回答**：让解释能够回到原始材料，保留尚未确定的部分。
- **可修正的记忆**：让用户能够补充、否认或撤回助手的理解。
- **清晰的数据边界**：区分本地记录与模型服务调用，明确数据去向。
